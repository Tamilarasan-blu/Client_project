# bluverse CRM - React 19 Application

A full-featured CRM application built with React 19 + Vite 6 + Tailwind CSS.

## Modules

- Dashboard (KPIs, charts, overview)
- Customers (company profiles, contacts)
- Sales (Proposals, Estimates, Invoices, Recurring Invoices, Payments, Credit Notes, Items)
- Subscriptions (Stripe integration)
- Expenses (billable/non-billable tracking)
- Contracts (active, expired, types)
- Projects (status tracking, team, progress)
- Tasks (status workflow, assignment)
- Support (ticket management with thread view)
- Leads (lead pipeline, conversion tracking)
- Estimate Request (web forms)
- Knowledge Base (articles, groups, kanban)
- Utilities (Calendar, Announcements, Activity Log, Bulk PDF, Media, Ticket Pipe Log)
- Reports (Sales, Expenses, Expenses vs Income, Leads, Timesheets, KB Articles)
- Setup (General, Company, Localization, Email, Finance, Features, Integrations, etc.)
